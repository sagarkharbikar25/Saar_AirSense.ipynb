# Data Source

## Primary dataset

- **Dataset:** Air Quality Data in India
- **Publisher:** Kaggle contributor Rohan Rao
- **URL:** https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india
- **Expected raw file:** `city_day.csv`
- **Expected location:** `data/raw/city_day.csv`

The dataset contains daily city-level AQI and pollutant measurements for Indian cities. The notebook records the source schema and applies explicit missing-value and date-cleaning rules before producing analysis outputs.

## Acquisition note

Download the dataset from the source URL and place the CSV in `data/raw/`. Do not commit credentials or Kaggle API tokens to the repository.
